# Aula 21 - Arquitetura de Computadores - Mod 4A

Demos continuidade ao bloco de exercícios práticos, focando-nos na resolução e revisão de problemas de cálculo de barramentos, velocidades de transferência e consolidação global dos conteúdos do módulo.
